# 참가자 소속 정보

## 현재 정책

별도의 공동체 마스터와 중그룹·셀 관리 화면은 운영하지 않습니다. 참가자가 신청하거나 본인 정보를 수정할 때 아래 소속을 선택 입력으로 받습니다.

- `middleGroupName`: 중그룹 이름
- `cellName`: 셀 이름

두 값은 `registrations`에 수련회 신청 당시의 문자열 스냅샷으로 저장됩니다. 관리자 역할이나 수련회 조와 연결된 권한 정보가 아닙니다.

## 운영 화면

관리자 참가자 목록, 상세, 체크인, 참가비, 수련회 조 편성 화면은 신청에 저장된 중그룹·셀 문자열을 표시합니다. 참가자가 본인 수정을 하면 소속도 함께 갱신되며 변경 이력이 남습니다.

관리자 참가자 목록의 `cellAssigned` 필터는 `cellName` 입력 여부를 기준으로 동작합니다.

## 기존 데이터 호환

Flyway V18은 기존 공동체 링크와 자유 입력 값을 가능한 범위에서 `middle_group_name`, `cell_name`으로 이관합니다. 과거 마이그레이션으로 생성된 공동체 테이블과 컬럼은 적용 이력 호환을 위해 물리적으로 남겨 두지만 현재 API와 화면에서는 사용하지 않습니다.

새로운 공동체 CRUD API는 제공하지 않습니다.

## 보안

- 소속은 관리자 역할과 분리된 참가자 속성입니다.
- 참가자는 관리자 계정이 아닙니다.
- 조회 키 해시를 API, 로그, 문서 예시에 노출하지 않습니다.
